MiniVCS — Mini Version Control System

MiniVCS is a C++-based mini version control and collaborative repository management system inspired by Git. It allows users to manage file versions, collaborate through repositories, and securely store project history.

 Features

* User Registration & Login
* Create and Manage Repositories
* Public & Private Repositories
* File Tracking and Commit Management
* Commit History and Diff
* Restore Previous Versions
* Branch Creation and Merging
* Basic Merge Conflict Detection
* Collaborators & Permissions
* Remote Repositories
* Clone, Push & Pull
* Smart Version Retention
* Automatic deletion of expired old versions

 Tech Stack

* Language: C++
* DSA: Hash Tables, Linked Lists, Trees, Graphs, Stacks
* Database: SQLite
* Frontend: HTML, CSS, JavaScript
* Backend: C++
* Storage: Local File System
* Data Format: JSON
* Hashing: SHA-256
* Communication: HTTP/REST
* Build Tool: CMake

 Unique Feature

Smart Version Retention: Users can set a retention period for old versions. Once a version expires, its stored snapshot is automatically deleted while the latest version is always preserved.

 Objective

To build a simplified version control system that demonstrates practical applications of C++, DSA, OOP, databases, file handling, authentication, networking, and collaborative repository management.
